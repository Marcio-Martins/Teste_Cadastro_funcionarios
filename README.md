# Cadastro de Funcionários — PHP

Projeto de estudo para praticar a construção de páginas web em PHP para gerenciamento de registros de funcionários.

## Funcionalidades identificadas na estrutura

- Cadastro de funcionários
- Listagem de registros
- Edição e exclusão de registros
- Exportação de dados para CSV
- Arquivos de configuração e estilos CSS

## Tecnologias

- PHP
- HTML
- CSS
- CSV para exportação de dados

## Estrutura do projeto

```text
Teste_Cadastro_funcionarios/
├── README.md
└── funcionarios/
    ├── cadastrar.php
    ├── cadastrar_form.php
    ├── config.php
    ├── editar.php
    ├── excluir.php
    ├── exportar_csv.php
    ├── index.php
    ├── listar.php
    └── styles.css
```

## Como executar

1. Instale um ambiente local com suporte a PHP.
2. Configure os parâmetros necessários em `funcionarios/config.php` de acordo com seu ambiente.
3. Inicie o servidor PHP a partir da pasta do projeto e acesse a aplicação pelo navegador.

A configuração exata depende do conteúdo de `config.php` e do banco de dados utilizado. Não publique senhas ou credenciais reais.
